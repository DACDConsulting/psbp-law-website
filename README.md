# PSBP Law Website Redesign

A modern, interactive static website redesign for **PSBP Law** (formerly Patel Law Group), a Dallas-area boutique firm specializing in:

- Immigration (EB-5 investor visas, employment-based, family)
- Real Estate Transactions
- Business / Corporate Transactions
- Securities, Private Offerings & M&A
- Estate Planning & Asset Protection

## Features

- Responsive design with navy & gold professional styling
- Animated stats counters (based on firm-reported figures)
- Mobile navigation
- Practice area cards with internal linking
- Testimonials section
- Blog / Insights section with real recent post titles and excerpts
- Team listing based on public information
- Contact page with accurate Irving and Frisco office details
- SEO-optimized titles and meta descriptions (revamped copy only — no invented claims)

## Pages

- `index.html` — Homepage
- `about.html`
- `practices.html` — Practice areas overview
- `immigration.html`
- `real-estate.html`
- `team.html`
- `blog.html`
- `contact.html`

## Notes

- This is a **redesign prototype** built from publicly available content on [psbplaw.com](https://psbplaw.com).
- It does **not** create an attorney-client relationship.
- Additional practice pages (business, securities, estate, asset-protection, videos) can be expanded as needed.
- Ready for static hosting (Bolt, Netlify, Vercel, GitHub Pages, etc.).

## Local Preview

Open `index.html` in a browser, or serve the folder with any static server.
